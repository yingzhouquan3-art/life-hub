怎么用

  1. 最简单：手机和这台电脑连同一个 WiFi，直接用上面的地址。数据不出这个局域网。
  2. 把上面那条带 token 的地址发到手机上（微信发给自己最快），点开。
  3. 页面会把令牌存进手机，之后地址栏里的 token 会自动抹掉。
  4. 在手机浏览器里选「添加到主屏幕」，就有一个独立的随手记图标了。
连不上怎么办：学校和公共 WiFi 常开「客户端隔离」，同一网络里的设备互相看不见。 这时可以用手机开热点、让电脑连上去，一样是同一个局域网。
想出门在外也能连，就得装 Tailscale 这类工具；装不上也不影响上面的局域网方式。
