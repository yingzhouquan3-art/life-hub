# 我的生活中枢

> 给自己使用的一体化个人生活平台。原“财富自由指南灯”现在是其中的个人账本模块。

## 当前模块

- **生活总览**：把六个日常维度的今日状态汇总在一页，并给出轻量的下一步提示
- **生活轨迹**：无需先想关键词，按时间浏览账本、身体、学习等全部来源记录，支持模块、类型与日期筛选
- **生活日历**：按月份统一查看八个来源模块的生活事实、待办和固定账单安排
- **个人目标**：管理长期生活方向、目标状态和阶段里程碑，目标日期接入生活日历
- **个人账本**：完整保留原有账户、交易、预算、规划、月度复盘和人生方格
- **个人健身**：活动记录 + 动作库、组数×重量×次数、训练容量与个人纪录
- **身体指标**：体重、体脂与围度，每天一条可更新，含七日均值曲线
- **个人饮食**：记录每餐或饮水；热量、蛋白质和饮水数值均可留空
- **睡眠与恢复**：每天一条可更新的睡眠、精力和心情记录，不做医疗判断
- **学习与专注**：记录已完成的学习时段；内置番茄钟，倒计时存在后端，刷新或换设备都不丢，结束后按实际分钟数记一笔
- **日程与习惯**：管理一次性待办、逾期状态、每日习惯和连续完成天数
- **日记与复盘**：每天写亮点、困难、感谢或自由记录，并查看周一至周日的跨模块事实快照
- **全局生活搜索**：随时按 `Ctrl+K` 搜索全部来源模块，并直接跳转到记录所属模块
- **洞察**：同期变化、数据健康度与标签总览集中在一页
- **待确认捕获**：手机上的支付通知与银行短信先落成待确认条目，确认后才变成交易
- **商户分类记忆**：确认过一次「星巴克→餐饮」，下次同一商户自动预选；学错可以删
- **手机端随手记**：`/m/` 是手机专用的精简页面；离线时已打开的页面仍能记，记录排队后自动补发
- **手机端打卡**：习惯与待办可以在手机上直接点；离线排队补发时发的是「设成已完成」而不是「切换」，迟到的补发不会把已经做好的事撤销
- **趋势**：按周 / 按月看每个指标怎么走；变化按有记录那些天的日均算，记录太少就明说不比较，不补零也不评价
- **每日提醒**：只在当天什么都没记时才弹一次本机通知；记过了、或服务没在跑，都不打扰。不需要管理员权限，随时可移除
- **就地改账**：记错的金额、日期、分类可以直接改，不必删了重记；由固定账单支付生成的交易会拒绝修改并说明原因
- **统一导入口**：丢一个文件进去，它先认出这是什么、说出依据、再决定写进哪个模块；认不出就直说，不硬套
- **月度账单对账**：导入微信/支付宝账单，与已有交易比对，只补差额不重复入账；每行按商户规则猜好分类，可逐行改，**但导入不会把猜测变成规则**
- **收集箱**：随手记下还没想好归属的事，之后再归档；归档只标记去向不复制内容
- **订阅总览**：固定支出支持月付/季付/年付，回答「我订了多少东西、一年花多少」
- **跨模块标签**：一个 `#考研` 同时贴在学习记录、待办和支出上，随时聚合查看
- **同期变化**：看两个指标是不是一起动——只呈现相关，绝不宣称因果
- **数据健康度**：哪些模块最近没在记，用来发现某条记录习惯正在断掉
- **运动数据导入**：把华为运动健康等 App 导出的运动与体重记录对账后补进来
- **本地自动备份**：每次启动自检并留一份快照，「上次备份多久之前」在数据中心一眼可见

生活轨迹和生活日历都是只读投影，不复制或修改来源记录；生活事实与生活安排会分开显示。个人目标与账本中的储蓄目标含义不同：前者记录生活方向，后者标记资金用途。

全局搜索同样只读：没有结果只代表当前关键词和筛选范围内没有匹配，不会改动或复制来源数据。

平台化迁移不会修改既有交易。家庭生活费仍然属于家庭支持，不会被算作自主收入。

## 个人账本原则

它不会再把所有入账都笼统地称作“财富自由”：
- 家庭生活费和起始存款 → 蓝色的**支持资金续航**
- 奖学金、兼职、实习、个人项目、投资等 → 金色的**自主所得**
- 自主生活覆盖率 = 自主收入 ÷ 已记录支出
- 人生方格展示当前可支配余额按日均花销能够支撑的天数

## 个人账本能力

- **今天主页**：集中显示今日可花、今日支出、预算余量、下次生活费、近期账单和目标
- **一句话记录**：一句话自动判断属于账本、健身、饮食、睡眠、学习还是待办，
  给出可编辑预览并支持一键改判；改判后由后端按新归属重新解析，确认后才落库
- **大学生学期预算**：按学期起止日期、总预算和在校/寒暑假模式判断消费节奏
- **多账户真实余额**：银行卡、微信、支付宝、校园卡、现金和其他账户
- **交易归属**：每笔收入或支出必须落到具体账户
- **账户间转账**：银行卡、微信等账户之间移动资金，不重复计算收入或支出
- **余额校准**：实际余额不一致时只记录差额，不伪造一笔消费或收入
- **支出分类**：餐饮、交通、学习、住宿、医疗、娱乐、社交、数字服务和其他
- **收入来源**：家庭生活费与各类自主收入分开统计
- **资金驾驶舱**：本月现金流、分类支出、账户余额与近六个月自主收入/支出趋势
- **规划中心**：储蓄目标、生活费到账周期、月度预算与月底余额预测
- **预算预警**：分类预算达到 80% 提醒，超过预算标红
- **安全导入**：CSV 先预览再确认，坏行整批拦截、重复内容防重、支持整批撤销
- **固定支出日历**：按月显示固定账单、逾期和三日内到期提醒
- **月度复盘**：净现金流、支出变化、最大分类、储蓄率与固定账单完成情况
- **数据中心**：全局交易搜索、十二个月年度报告和年度 CSV 导出
- **完整备份恢复**：JSON 快照覆盖全部业务数据，恢复前自动生成回退数据库
- **规划不改账**：预计生活费不会自动成为收入，目标预留也不会增加账户余额
- **人生方格**：继续保留生活续航的沉浸式可视化

## 快速开始

### Windows（推荐）

1. 双击 **`启动我的生活中枢.cmd`**（旧启动器仍可继续使用）。
2. 首次启动会自动准备本地运行环境，请按提示等待。
3. 浏览器会自动打开；平时不需要输入任何终端命令。
4. 使用结束后，双击 **`停止我的生活中枢.cmd`**。

如果电脑没有可用的 Python，启动器会打开 Python 官方下载页并说明安装方法。数据仍然只保存在本机。

### macOS / Linux

```bash
chmod +x run.sh
./run.sh                       # 自动 venv + 装依赖 + 开浏览器
```

访问 **http://127.0.0.1:8766**

### 在手机上随手记

**最简单的方式：手机和电脑连同一个 WiFi**，不需要装任何东西。

1. Windows 双击 **`启动并允许手机访问.cmd`**；macOS / Linux 用 `LIFE_HUB_HOST=auto ./run.sh`。
2. 配对页面会自动打开（也可以手动访问 **http://127.0.0.1:8766/pair.html**），复制那条带 token 的地址。
3. 把地址发到手机上打开，选「添加到主屏幕」，就有一个独立的随手记图标。

`LIFE_HUB_HOST` 的取值：

| 值 | 含义 |
|---|---|
| 不设置 | 只监听本机，手机连不进来 |
| `auto` | 有 Tailscale 用 Tailscale，否则用当前局域网 |
| `lan` | 只用当前局域网（同一个 WiFi） |
| `tailscale` | 只用 Tailscale（出门在外也能连） |
| 具体地址 | 直接指定，只接受内网或 Tailscale 地址 |

找不到目标网络时一律退回只监听本机；`0.0.0.0` 会被明确拒绝。

**连不上时**：打开 `/pair.html`，页面上「连不上？先看这里」会逐条检查并给出该做什么。
手机访问要同时满足三件事，缺一条现象都是「网页打不开」：

| 关卡 | 常见原因 |
|---|---|
| 后端监听在局域网地址 | 用了旧启动器，只监听本机 |
| 防火墙放行 8766 端口 | **Windows 默认拦截所有入站连接**，需要手动加规则 |
| 手机和电脑在同一网络 | 学校/公共 WiFi 常开客户端隔离，同网设备互相看不见 |

第三条查不出来。前两条都通过还是连不上，多半就是它，改用手机热点即可。

放行端口需要管理员权限：双击 **`添加防火墙规则.cmd`**，在弹出的系统提示里点「是」。
它只加一条限定在「专用网络」的放行规则，并询问是否把当前网络改成专用；
不会关闭防火墙，也不改动其他规则。不想用脚本的话，配对页也给出了等价命令。

手机端只做三件事：一句话记录、确认捕获、看今天记了什么。报表和复盘留在电脑上。

**关于「安装成应用」和离线**：浏览器只把 https 和 localhost 当成安全来源，
而手机是通过 `http://192.168.x.x` 直连电脑的。所以：

- **没有「安装应用」按钮**，Service Worker 也不会注册，因此**没有离线外壳**；
- 仍然可以在浏览器菜单里选「添加到主屏幕 / 添加到桌面」，
  那是一个书签快捷方式——能一键打开，但仍带地址栏；
- 离线时**已经打开着的页面照样能记**，记录进本地队列、联网后自动补发；
  但页面没打开时是打不开的。

想要真正的安装与离线，需要 https 且证书被手机信任——目前没有做。

### 可选云端模式：电脑关机也能访问

如果不想每次先启动电脑，可以把平台部署为自己的单用户云端实例。云端模式提供：

- 独立登录页、HttpOnly 安全会话和连续错误密码节流；
- 手机、平板和电脑访问同一个 HTTPS 地址，看到的是同一份数据；
- SQLite 保存在持久磁盘，部署更新不会清空账本；
- `/api/health` 只报告服务是否存活，不读取生活数据；
- 本地启动方式完全保留，且默认仍然是本地模式。

仓库已提供 `Dockerfile` 和 `render.yaml`。以 Render 为例：

1. 把仓库放在自己的**私有** GitHub 仓库中；
2. 在 Render 用仓库中的 `render.yaml` 创建 Blueprint；
3. 按提示填写 `LIFE_HUB_PASSWORD`，至少 12 个字符，不要写进代码或聊天；
4. 部署完成后打开 Render 给出的 HTTPS 地址并登录；
5. 要沿用本地数据，在本地数据中心导出完整备份，再在云端恢复一次。

云端与本地不会自动双向合并。开始长期使用云端后，应把云端作为主数据副本；以后要迁回本地，也通过完整备份进行。Render 持久磁盘需要付费实例，因此代码准备完成不等于已经替你开通了云服务。

## 示例数据

刚装好的时候库是空的，每个分析页面都写着「还没有记录」，没法判断这东西
对自己有没有用。「账本 → 数据中心 → 示例数据」可以借你 60 天的记录看看，
覆盖账本、健身、学习、恢复、饮食、身体、习惯与待办。

它**不删除任何已有数据**，每写一条都登记在册，移除时按册精确删除，
只删自己写的那些。已经装过会拒绝再装。

数据刻意造得不完美——有的日子没记，有的指标缺一块。一份每天记满的示例
会让人对自己的真实记录产生错误预期，也会让「数据健康度」和「趋势」显得
毫无用处，而那两个功能存在的意义恰恰是应付不完整的记录。

依赖方向是单向的：`api` → `views` → `modules` → `core`。模块之间不互相调用，跨模块的汇总一律走 `views`。
数据库位置由 `core/db.py` 独占，其他地方不缓存路径。

**新增一个生活模块只需三步**：写 `modules/<name>.py` 并声明 `MODULE`（表、建表语句、备份列、清空顺序），
在 `modules/__init__.py` 的 `MODULES` 里登记，写 `api/<name>.py` 并在 `main.py` 装配。
建表、备份和恢复会自动覆盖到，不需要再改别处。

跑测试：

```bash
.venv/Scripts/python -m unittest discover -s tests -t .
```

## 核心公式

```
avg_daily_expense    = total_expense / tracking_days
account_balance      = opening_balance + account_income - account_expense
                       + transfer_in - transfer_out + balance_adjustments
current_balance      = Σ account_balance
support_pool         = Σ opening_balance + family_support_income
runway_days          = floor(current_balance / avg_daily_expense)
autonomy_coverage    = independent_income / total_expense
lit_count            = min(runway_days, future_cells)
```

> 数据是真相，动画是仪式。仪式服从真相。

## 隐私

默认本地模式下，所有生活模块数据都存储在 `data/ledger.db`，**不上传任何服务器**。
只有你主动配置云端实例并自行恢复备份时，数据才会进入你选择的云端宿主。

后端**默认只监听 `127.0.0.1`**。只有在你主动开启手机访问时，它才会额外监听
你自己的局域网地址或 Tailscale 地址——数据依然不经过公网，也不经过任何第三方服务器。
启动脚本**明确拒绝监听 `0.0.0.0`**，也拒绝任何公网地址。

局域网模式意味着**同一个 WiFi 下的其他设备能访问到这个端口**。静态页面本身不含数据，
接口则需要访问令牌。在不可信的公共网络上，建议改用手机热点或 Tailscale。

非本机的接口访问必须携带访问令牌，令牌保存在 `data/access-token.txt`，不进版本库。
在 `/pair.html` 可以查看或更换令牌；更换后已配对的手机会立刻失效。

局域网令牌不能当作公网密码。云端模式使用单独的密码登录和签名会话；密码只放在部署平台的 Secret 环境变量中。仓库、Docker 镜像、数据库和日志都不保存密码。

### 关于连接运动手环 / 健康 App

走的是**导出文件导入**，不是官方 API。原因有两个：

- 华为 Health Kit 之类的接口要注册应用、过审核，而且数据要绕一圈云端，
  与「数据只在本机」的前提冲突；
- Health Connect 只有原生安卓应用能读，本项目手机端是 PWA，读不了。

所以流程和月度账单一样：导出 CSV → 解析 → 和已有记录对账 → 只补没记过的 → 确认写入。
同一份文件重复导入不会让记录翻倍。列名映射按常见导出格式编写，
**未对真实导出文件验证**，第一次导入请先看预览。

### 关于通知监听的一个真实代价

如果你启用微信支付通知的自动捕获，微信的「通知显示消息详情」必须打开，
这意味着**你所有的聊天内容都会出现在通知栏，并被自动化应用读到**。
缓解办法是规则在手机本地严格过滤、只有匹配上的才发出请求，但这个代价本身消不掉。
不想接受的话，可以只用月度账单导入——覆盖率一样是 100%，只是延迟到月末。
